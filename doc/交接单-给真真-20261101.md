- D 盘：Bash 用 `/d/xxx`；写文件用 Python UTF-8 原生路径。

**代码**
- 改共享常量/函数 ⇒ **必须全量跑单测**（"相关"是猜出来的）；一条路由 ≠ 一个入口（先 grep 谁在调）。

- 组件内不许定义组件；hook 不许放在早退之后。
- **断言前先问"它钉的行为本身对不对"** —— 旧断言会把旧行为焊住（今天 tags 筛选那条就是这样）。
- 错误断言会把 bug 焊成正确行为；改 `||` → `??` 会释放出没设计过的空态。
- SQLite 唯一索引里 NULL 互不相同（唯一约束必须带 userId）。
- 时区：容器 UTC，日期筛选传绝对时刻（ISO），"哪一天"只在客户端算。
